# 🩺 Diabetes Prediction using Machine Learning

This project uses machine learning to predict whether a patient is likely to have diabetes based on medical attributes.  
It is part of my AI & Data Science specialization and serves as one of my portfolio projects for MS admissions.

---

## 📘 Project Overview

- Built a **classification model** using the Pima Indians Diabetes Dataset.
- Implemented in **Python**, using **Pandas, NumPy, Scikit-Learn, Matplotlib**.
- Achieved an accuracy of **~74%** with Logistic Regression.
- Contains:
  - Data preprocessing
  - Feature scaling
  - Train-test split
  - Model training
  - Evaluation metrics
